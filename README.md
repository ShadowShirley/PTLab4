## Основные результаты

- **NumPy:** `Tr(NM) = 111 564` (проверено через `sum(N ⊙ Mᵀ)`), `f` — вектор из 85 элементов,
  `g ≈ 4523.94` (зависит от случайного **p**, `seed = 42`).
- **Pandas, п. 2.1:** на борту было **18 женщин старше 50 лет**.
- **Pandas, п. 4.1:** утверждение «чем дороже билет, тем выше вероятность выжить» в целом **верно**:
  доля выживших растет от 22 % (самые дешевые билеты) до 58 % (самые дорогие), корреляция
  Спирмена ≈ 0.32; связь в основном объясняется классом каюты и в 3-м классе почти отсутствует.
